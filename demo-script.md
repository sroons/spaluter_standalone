| Time | Narration (voiceover) | Suggested visuals |
|---|---|---|
| 0:00–0:20 | Most synths start with one continuous sound and shape it over time. **Pulsar synthesis** does the opposite: it builds sound from an ultra-fast stream of tiny sonic particles. Those particles are called **pulsarets**. | Abstract animation of small pulses becoming a continuous waveform. |
| 0:20–0:45 | A **pulsaret** is a very short wave fragment, repeated rapidly. Think of it like a single brushstroke in a pointillist painting: one dot is simple, but thousands together create rich detail. | Zoom from single pulse to dense audio texture. Add label: “Pulsaret = tiny repeating wave fragment.” |
| 0:45–1:10 | Each pulsaret is shaped by a **window**. The window is the envelope around each tiny sound—how it fades in and out. A soft window sounds smoother. A sharp window sounds more percussive and bright. | Side-by-side animated envelopes: rounded vs sharp. Then show resulting smoother vs sharper waveform. |
| 1:10–1:30 | **Duty** controls how much of each pulse cycle is active versus silent. Higher duty means longer “on” time; lower duty means shorter bursts and more space between them. That changes rhythm, density, and edge. | Simple pulse train graphic with duty at 20%, 50%, 80%. |
| 1:30–1:55 | **Formants** are emphasized frequency zones—like color filters for sound. Even non-musicians hear this as vowel-like tone color: darker, brighter, hollow, nasal, or vocal-like. | Frequency spectrum with highlighted bands labeled F1, F2, F3; morph between tone colors. |
| 1:55–2:20 | **Spaluter** turns these ideas into a practical instrument. It began as a SuperCollider patch, then became a desktop app with a custom interface so players could shape pulsar sound without needing SuperCollider code. | Show early SuperCollider code screenshot, then transition to Spaluter desktop UI. |
| 2:20–2:45 | The project expanded quickly: cross-platform installers for macOS, Windows, and Linux/Raspberry Pi; startup checks for SuperCollider; and an OSC bridge so the UI can control the synthesis engine in real time. | Timeline graphic with icons: Mac, Windows, Pi, OSC link. Use README snippets or installer visuals. |
